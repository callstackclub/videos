# Call Stack Club: code from the videos

Coding interviews and system design, animated step by step. Here is the code behind every video on **[youtube.com/@callstackclub](https://www.youtube.com/@callstackclub)**.

Every algorithm folder has the exact solution shown on screen, plus the tests that run it. The animations in the videos are recorded from this code running, so what you see is what it does.

## How to use
```bash
git clone https://github.com/callstackclub/videos
cd videos/two-sum
pip install pytest
pytest -q
```
Python 3.10+ for the solutions, 3.13+ for the HTTPS companion script. No other dependencies.

Spot a bug or have a better solution? Open an issue or a pull request. If it's good, it might end up in a video.
