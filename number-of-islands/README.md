# Number of Islands: BFS vs DFS, Step by Step

▶ **Watch:** https://youtu.be/p1UPXvmwOKc

## Problem

Given a 2-D grid of '1' (land) and '0' (water), count the islands, where land connects horizontally and vertically. Solve with BFS and with DFS.

## In the video

1. What counts as an island
2. Scan, then flood
3. BFS: rings with a queue
4. DFS: change one word
5. Which one should you use?
